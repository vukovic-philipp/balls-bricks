# Balls & Bricks

Static, dependency-free brick-shooter for mobile and desktop. Open `index.html` (or serve the folder with any static host, e.g. GitHub Pages).

**Play:** touch/click anywhere and pull back (slingshot style), release to fire. Clear bricks before they reach the bottom row; green rings add a ball. Use the 1×/3× button to fast-forward. Progress is saved in `localStorage`.
