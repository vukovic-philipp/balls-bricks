# Balls & Bricks

Static, dependency-free brick-shooter for mobile and desktop. Open `index.html` (or serve the folder with any static host, e.g. GitHub Pages).

**Play:** touch/click and drag to aim (the ball shoots toward your finger, with a dotted preview), release to fire; release near the floor to cancel. Clear bricks before they reach the bottom row; green rings add a ball. Use the 1×/3× button to fast-forward. Progress is saved in `localStorage`.
